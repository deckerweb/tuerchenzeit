# Help and security

[Deutsch](Help-Deutsch)

## Questions and practical help

Start with the [illustrated guide](Guide-English) or [FAQ by topic](FAQ-English). For questions about using Türchenzeit, visit [Discussions](https://github.com/deckerweb/tuerchenzeit/discussions).

## Reporting a bug

Use [Issues](https://github.com/deckerweb/tuerchenzeit/issues) for ordinary reproducible bugs. Include the plugin, WordPress and PHP versions, the active theme, whether Multisite is used, and a short description of the steps and expected result. Remove credentials, private contents and personal information from examples and screenshots.

## Private security reports

Report suspected vulnerabilities through [GitHub’s private reporting form](https://github.com/deckerweb/tuerchenzeit/security/advisories/new), following the [security policy](https://github.com/deckerweb/tuerchenzeit/security/policy). Keep exploit details out of public issues and discussions.

## Downloads

Download the installable plugin ZIP from [Downloads & Releases](https://github.com/deckerweb/tuerchenzeit/releases). Use the attached plugin ZIP rather than GitHub’s automatically generated source archives.
